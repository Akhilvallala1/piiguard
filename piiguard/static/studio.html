    Fair questions
    
  
    Does it need NemoClaw?
    No. Anything that speaks the OpenAI chat API can point at it: the OpenAI SDK, LangChain, curl. Run piiguard serve --upstream with any OpenAI, Ollama or vLLM address. NemoClaw is one place it plugs in, as a middleware.
    
  
    Does my text leave my machine?
    Only the redacted version. The rules run where the proxy runs. The optional model classifier and the learning loop do call a model, and the loop only ever sees synthetic attacks.
    
  
    Does it learn from live traffic?
    Never. You run piiguard improve. A change ships only if it cuts leaks on validation data, keeps clean text clean and forgets nothing it caught before. Every kept change is a tagged commit you can undo.
    
  
    What does it still miss?
    About a quarter of fresh attacks. Names need a detector. Tricks it never trained on rarely transfer: spelled-out and reversed numbers fixed none when held out. Unseen formats broke 12 attacks it used to stop.
    
  
    How do I add my own ID?
    Two lines in guard/rules.yaml, a name and a pattern, or the box above. To catch the disguised versions too, give the red team examples of it and run the loop.
    
  
    What does it cost?
    Redaction is free and takes about a tenth of a millisecond. Every experiment in the report, learning included, cost under five dollars of model time.
