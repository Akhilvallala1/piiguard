How it works

A Nemotron 3 Super red team hides PII twelve ways inside search queries, tool calls, logs and code. A Nemotron 3 Super coach reads every leak and rewrites the regex rules. A gate keeps a change only if validation leaks drop and clean traffic stays clean. Accepted generations are committed and tagged; rejected ones are reverted and logged. Held-out attacks are scored but never shown to the coach.

The rules are the cheap path, about a millisecond and no tokens. A Nemotron 3.5 Lightning classifier sits behind them as the expensive safety net. The loop moves the cheap layer toward what the expensive layer catches.

Unlearning has a tripwire: pruning drops a rule only if nothing changes on train and validation, then checks held-out before committing. Here it found ten dead-looking rules and refused, because held-out leak would have risen.
